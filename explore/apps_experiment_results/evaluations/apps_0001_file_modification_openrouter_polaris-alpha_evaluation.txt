    - numbers formed by decreasing one digit of x’s prefix and filling the rest with 9s
    - (and includes that via the prefix-decrease loop; plus an all-9s shorter candidate)
  - This is a standard solution for: “find y ≤ x minimizing digit sum; if tie, choose smallest y”.

      - For x=100, the implemented search yields 99 due to the prefix-decrease logic used in earlier versions; but the final version’s reasoning above shows a bug: it actually incorrectly favors lower sum (100) and would return 100. So:
        - The final code is inconsistent with the example 99 and with tests.

- Solution quality assessment:

  - However:
